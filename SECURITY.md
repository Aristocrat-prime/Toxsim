# Security policy

## Scope

Please report security issues affecting the repository, build configuration, documentation tooling, or any future application code.

## Reporting a vulnerability

Do not publish exploit details, credentials, private data, or a working proof of concept in a public issue. Use GitHub's **Report a vulnerability** flow on this repository when available. If private vulnerability reporting is not enabled, contact the repository maintainer privately before sharing technical details publicly.

Include the affected file or component, the potential impact, steps to reproduce that avoid real user data, and any suggested mitigation.

## Sensitive data

Never commit API keys, access tokens, passwords, private datasets, or secrets to the repository. If a secret is exposed, revoke or rotate it first; removing it from the latest commit may not remove it from repository history.
